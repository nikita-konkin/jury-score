# Фикстуры программ

Реальные программы в формате `conf.program/v1`. Эталон для тестов, пример для ботов и проверка того, что схема покрывает настоящие мероприятия.

| Файл | Мероприятие | Что проверяет |
|---|---|---|
| `rwp-2026.program.json` | RWP-2026, 7–9 октября 2026, ПГТУ | авто-время по регламенту, якоря, конкурсные доклады с жюри; коды `s1-1…s4-7` совпадают с ID в `legacy/jury-score` |
| `rwp-2026.broken.json` | то же, время секции 4 как в исходном PDF | ошибки `TIME_BACKWARDS` и `TIME_OVERLAP` с точными путями |
| `rrv-2023.program.json` | РРВ-28, 15–19 мая 2023, ПГТУ | 5 дней, до пяти параллельных секций в разных залах, несколько секций в одном зале, стендовые доклады, выездные события; 164 элемента |

## РРВ-2023

Собрана скриптом [`tools/import/rrv2023.js`](../tools/import/rrv2023.js) из «Программа конференции_Версия_5.docx» (таблица-сетка: строки — время, колонки — залы). Секции докладов в общих залах («Секции 3, 4, 7») взяты из «Списка заявок РРВ.docx» по названию доклада. Контакты из списка заявок в фикстуру не переносятся.

Правки относительно исходника:

- залы ПГТУ записаны единообразно («ауд. 403», корпус — в `rooms[].building`), в программе одна аудитория встречалась в трёх написаниях;
- секция 6 названа по списку заявок («Физические проблемы радиолокации, радионавигации и радиосвязи»): в программе её заголовок по ошибке повторял секцию 2.

Предупреждения проверки — настоящие огрехи исходника, их ждёт тест: три `SPEAKER_NOT_IN_AUTHORS` (у «Павловой» нет инициалов среди авторов, «А. Е.» вместо «Н. Г.» Котонаевой, «В.» вместо «В. В.» Ахиярова) и `NO_ROOM` у товарищеского ужина (место не указано).
