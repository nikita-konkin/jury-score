# Локальный обработчик conf-kit

Разбирает материалы мероприятия (заявки, информационные письма, списки докладов) моделью в LM Studio на вашем компьютере. Материалы с персональными данными не уходят во внешние сервисы.

Обработчик сам обращается к серверу и забирает задачи ваших мероприятий. Соединение только исходящее, поэтому он работает за NAT и не требует открытых портов. Если компьютер выключен, задача ждёт в очереди.

## Запуск

1. Установите Node.js 18 или новее и [LM Studio](https://lmstudio.ai). Загрузите модель и включите сервер (Developer → Start Server, порт 1234).
2. Получите ключ: «Моё мероприятие» → «Обработка на своём компьютере» → «Получить ключ обработчика». У ключа одно право — `process_jobs`, и он видит только задачи ваших мероприятий.
3. В папке conf-kit выполните команду со страницы:

```bash
node worker/worker.mjs --server https://conf.konkin-nikita.ru --key ck_…
```

Флаги:

| Флаг | Переменная окружения | По умолчанию |
|---|---|---|
| `--server` | `CONF_URL` | — |
| `--key` | `CONF_WORKER_KEY` | — |
| `--lm` | `LMSTUDIO_URL` | `http://localhost:1234` |
| `--model` | `LMSTUDIO_MODEL` | модель, загруженная в LM Studio |
| `--interval` | — | 30 с между опросами пустой очереди |
| `--attempts` | — | 2 попытки: вторая — исправление по отчёту проверки |
| `--once` | — | обработать одну задачу и выйти |

## Задачи

- **Программа из текста.** Информационное письмо или черновик программы превращаются в документ `conf.program/v1`. При применении он заменяет программу целиком, прежняя остаётся в истории версий.
- **Доклады из текста.** Заявки или список докладов превращаются в доклады без контактов. При применении они добавляются в выбранное заседание.

## Проверка результата

Результат проверяется дважды: `shared/model.js` здесь и сервер при приёме. Если найдены ошибки, модель получает отчёт и исправляет ответ. Если ошибки остались, задача получает статус «ошибка», а владелец видит отчёт.

Применить результат может только владелец мероприятия, после просмотра. Контакты (e-mail, телефоны) из ответа модели вырезаются.
