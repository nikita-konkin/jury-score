# Оценка докладов · RWP-2026

Мобильная страница для конкурсной комиссии. Эксперт открывает ссылку на телефоне, вводит фамилию и код комиссии и ставит баллы докладам по шести критериям. Оценки сохраняются автоматически в Google-таблицу. Регистрация не нужна.

- **Эксперт** оценивает доклады, отмечает «доклад не состоялся» или «воздерживаюсь» и оставляет комментарий. Без связи оценки копятся на телефоне и отправляются, когда сеть появится.
- **Администратор** входит со своим кодом. Ему доступны рейтинг (общий и по секциям), статистика (средние по секциям и критериям, распределение баллов, прогресс и строгость каждого эксперта, доклады с наибольшим расхождением оценок) и выгрузка в CSV.

Место определяется по среднему суммарному баллу экспертов. Учитываются только полностью заполненные оценки, одинаковые средние делят место.

## Развёртывание

1. Создать Google-таблицу → Расширения → Apps Script → вставить [`Code.gs`](Code.gs).
2. Задать в нём свои `ACCESS_CODE` (для экспертов) и `ADMIN_CODE` (для администратора).
3. Выполнить функцию `setup` и разрешить доступ к таблице.
4. Развернуть → Новое развертывание → Веб-приложение: выполнять от имени «Я», доступ «Все». Скопировать URL `…/exec`.
5. Вставить URL в `CONFIG.SCRIPT_URL` в [`index.html`](index.html) и закоммитить в `main`.
6. Settings → Pages → Deploy from a branch → `main` / root.

После правок `Code.gs`: Управление развертываниями → изменить → Новая версия (URL не меняется).

Пока `SCRIPT_URL` пустой, страница работает в демо-режиме: всё хранится только в браузере.
