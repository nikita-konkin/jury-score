# conf-kit

Универсальный сервис для конференций и мероприятий: конструктор программы, публичная программа для участников, печатные документы (программа, «на дверь», протоколы, дипломы), конкурс докладов с оценкой жюри и приём заявок.

Главный сценарий — создание программы чат-ботом: бот получает материалы мероприятия, через API собирает программу целиком и отдаёт человеку ссылку-приглашение на готовый черновик.

Вырос из инструмента оценки докладов RWP-2026 — он сохранён в [`legacy/jury-score/`](legacy/jury-score/), старая ссылка GitHub Pages продолжает работать.

## Состояние

Готовы ядро (этап 1), API для чат-ботов (этап 2), мобильный конструктор (этап 3), публичная программа (этап 4), документы (этап 5), жюри (этап 6), заявки (этап 7), десктопная версия (этап 8) и локальный обработчик (этап 9):

- [`public/schema/program.v1.json`](public/schema/program.v1.json) — JSON Schema документа программы `conf.program/v1`;
- [`shared/model.js`](shared/model.js) — нормализация, авто-время по регламенту, проверки (наложения залов, докладчик в двух местах, время «наоборот» и т. д.), разбор документа на строки БД и сборка обратно;
- [`pb/`](pb/) — PocketBase: коллекции программы с версиями, API-ключи, обратная связь от ботов, API:

  | Метод | Назначение |
  |---|---|
  | `POST /api/v1/programs/validate` | проверка программы без сохранения |
  | `POST /api/v1/events` | черновик по API-ключу (или вошедшим пользователем): `invite_url`, `preview_url`, `draft_token` |
  | `GET`/`PUT /api/v1/events/{id или slug}/program` | программа в формате `conf.program/v1`; замена — новая версия |
  | `GET`/`POST /api/v1/claim/{токен}` | предпросмотр по приглашению и принятие черновика в свой аккаунт |
  | `GET /api/v1/events/{id}/versions[/{no}]` | история версий и одна версия целиком |
  | `GET /api/v1/events/{id}/program.ics` | календарь для подписки (`?items=1` — все элементы, `?item=<код>` — один) |
  | `POST /api/v1/events/{id}/invite`, `/publish`, `/unpublish` | приглашение соавтора, публикация |
  | `POST /api/v1/feedback`, `GET /api/v1/changelog` | обратная связь от ботов и список изменений |
  | `GET`/`POST /api/jury/{id или slug}` | оценки жюри по коду комиссии: `ping`, `mine`, `all`, `save`, `delete` |
  | `GET`/`POST /api/v1/events/{id}/jury` | коды комиссии для владельца и выпуск новых кодов |
  | `GET`/`POST /api/apply/{id или slug}[/{токен}]` | форма заявки, отправка, своя заявка по ссылке и её отзыв |
  | `GET /api/v1/events/{id}/applications`, `POST …/applications/{заявка}` | заявки с контактами для владельца: принять в заседание, отклонить, вернуть |
  | `GET`/`POST /api/v1/events/{id}/jobs[/{задача}]` | задачи для локального обработчика: поставить, посмотреть, применить, отменить |
  | `POST /api/v1/jobs/claim`, `POST /api/v1/jobs/{задача}/result` | обработчик забирает задачу и возвращает результат (ключ `process_jobs`) |
  | `GET`/`POST /api/v1/worker-keys` | ключ обработчика для своего компьютера, отзыв |

- [`public/llms.txt`](public/llms.txt) и [`public/openapi.json`](public/openapi.json) — инструкции для ботов и GPT Actions;
- [`mcp/`](mcp/) — MCP-сервер для Claude, LM Studio и других клиентов (stdio и HTTP);
- [`web/`](web/) — мобильный фронтенд для браузеров с 2018 года: принятие приглашения, мои мероприятия, публикация, публичная программа, «Создать из ответа чат-бота» (для ботов без инструментов);
- программа для участников: «сейчас / далее» по часам мероприятия, поиск и фильтры, подписка в календаре (.ics), обновление без перезагрузки, копия на случай без связи;
- документы A4 с предпросмотром на телефоне: программа (как официальная программа конференции), таблички «на дверь», протоколы секций, сертификаты участников, итоги конкурса и дипломы; печать в PDF и выгрузка в Word;
- конкурс докладов: эксперт входит по ссылке с фамилией и кодом комиссии, без аккаунта; оценки сохраняются на телефоне и уходят на сервер сами, в том числе после пропадания связи; администратор видит рейтинг, места в секциях, статистику, выгружает CSV и удаляет ошибочные оценки (они уходят в архив);
- заявки на доклады: форма без аккаунта с согласием на обработку персональных данных, защита от спама, ссылка участника на свою заявку (статус, причина отказа, отзыв); владелец принимает заявку в заседание — она становится докладом новой версии программы, контакты в программу не попадают и стираются через год после мероприятия;
- десктоп (от 900 px): конструктор в три колонки — дерево дней и заседаний, список элементов, предпросмотр печатной программы; листы правки — боковой панелью, перетаскивание элементов мышью внутри заседания и в другое заседание, горячие клавиши (Ctrl+S, Ctrl+Z, Esc, Alt+↑/↓); таблица людей программы с поиском разного написания; рейтинг жюри и заявки — широкими таблицами;
- конструктор программы на телефоне: дни → заседания → элементы, правка в нижних листах, порядок кнопками, проверка на месте, отмена, черновик без потери при перезагрузке, история версий с откатом, доклады из таблицы (.xlsx, .csv, .docx), новое мероприятие и «по образцу»;
- [`worker/`](worker/) — локальный обработчик: разбирает заявки и письма моделью в LM Studio на компьютере организатора (соединение только исходящее), результат проверяется `model.js` и применяется владельцем новой версией программы;
- [`tests/bots/local_bench.mjs`](tests/bots/local_bench.mjs) — замер того, как локальная модель в LM Studio собирает программу из материалов;
- [`fixtures/`](fixtures/) — программы RWP-2026 (и вариант со сбитым временем секции 4) и РРВ-2023.

План развития — [`docs/PLAN.md`](docs/PLAN.md).

## Проверка

```bash
npm install
npm test             # юнит-тесты
npm run test:api     # API против временного PocketBase (нужен бинарник, путь — в PB_BIN)
npm run test:mcp     # MCP-сервер
npm run test:e2e     # сквозные сценарии в Playwright (pip install playwright pypdf python-docx)
```

## Запуск

```bash
npm run pb:superuser -- admin@example.com 'пароль'
npm run pb                                   # сборка фронтенда и PocketBase на 127.0.0.1:8090
node scripts/pb.js apikey create "Claude"    # ключ для бота
```

Адрес для ссылок-приглашений задаётся переменной `CONF_PUBLIC_URL` или полем Application URL в настройках PocketBase.
